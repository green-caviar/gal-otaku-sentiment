# レポート：オタク・ギャル風の投稿のポジ／ネガ判定

自然言語処理 第2回 演習「ポジ／ネガ判定を2つのアプローチで」のレポート。オタク・ギャル風の SNS 投稿を、ルール（単語リスト）と LLM で判定して比べる。

## タスク定義

- 入力：オタク・ギャル風の SNS 投稿1件（短文）
- 出力：pos（ポジティブ）／neg（ネガティブ）の2値
- ラベルの基準：使われている語の辞書的な意味ではなく、書き手の本当の気持ちで付ける。
  例：「まじ尊すぎて死ぬ」は「死ぬ」を含むが、推しへの感動なので pos。
- 迷う投稿：同じ語が文脈で逆の意味になるもの（11・12 の「キャパい」）。
  何に対する気持ちか（推しか、自分の寝坊か）で判断した。

## データ

`data/labeled_data.csv`（12件、pos 6件・neg 6件）。投稿はすべて自分で書き、正解ラベルも自分で付けた。公開データは使っていない。

| 型 | 件数 | id |
|---|---|---|
| 否定語なのにポジ | 3 | 1, 4, 5 |
| 素直なポジ | 2 | 7, 8 |
| 素直なネガ | 3 | 2, 3, 6 |
| 皮肉（ポジ語なのにネガ） | 2 | 9, 10 |
| 迷う投稿（同じ「キャパい」で逆） | 2 | 11, 12 |

- 型を考えるときに、生成AI（Claude）が出したギャル語・オタク語の例文を参考にした。データの文は、それを見て自分の言葉で書き直したもの。
- 4「逆に会いたくないまであるわー」は、会う頻度が多すぎるほど仲の良い友達への好意として pos にした。この根拠は本文に書かれていない。

## 手法

- **ルール**（`src/run.py`）：語の辞書的な意味で、ポジの語とネガの語のリストを作った。ネガの語の数がポジの語の数より多ければ neg、それ以外（同数・どちらも0件）は pos とする。
  - ポジ：最高、好き、推す、尊、美し、盛れ、あげ、優勝、さすが
  - ネガ：死ぬ、だりー、だるい、きも、悪すぎ、長すぎ、えぐい、キャパい、会いたくない、無理
  - リストはデータを見ながら作ったので、ルールに有利な面がある。
- **LLM**：次のプロンプト（`llm/prompt.txt`）で判定させ、「ポジ」→pos、「ネガ」→neg に直した。

```text
次の投稿を書いた人の本当の気持ちがポジティブかネガティブか、
「ポジ」か「ネガ」で答えてください。
使われている語の表面ではなく、書き手の本当の気持ちで判定してください。
投稿：{text}
```

## 設定

- LLM：Claude Sonnet 5.5（`claude-sonnet-5-5`）。Claude Code のサブエージェントとして実行した。正解ラベルは渡していない。
- 日付：2026-11-16
- 聞き方：12件を1回にまとめて聞き、「番号: ポジ／ネガ」の形で答えさせた。各投稿は1回ずつしか聞いていない。
- 追加の比較：4 を単独で聞いたものと、末尾に「笑」を付けたものを、それぞれ別の新しいエージェントに1回ずつ聞いた（`llm/extra_4.csv`）。
- Python 3.15.0、標準ライブラリだけ。

## 考察

ルールは語の表面で誤り、LLM は文脈から多くを補えた。ただし、本文にない文脈に依存する投稿は、どちらも当てられなかった。

**ルールの誤り：10「サイト待ち時間長すぎ笑　さすが運営、期待を裏切らないな－」**
「さすが」をポジ、「長すぎ」をネガとして拾い、数が同じになって既定値の pos に落ちた。皮肉は、語の向きと書き手の気持ちが逆になるので、単語リストでは捉えにくい。LLM は「待ち時間長すぎ笑」からの流れで、皮肉として neg と判定できた。
また、ルールが当たった 1・7・11 も、ポジの語とネガの語が同数で既定値の pos に落ちただけで、既定値を neg にすれば3件とも外れる。正解数だけでは、ルールがどこまで分かっているかは測れない。

**LLM の誤り：4「逆に会いたくないまであるわー」**
「会いたくない」を文字どおりに読んで neg にした。pos とした根拠（会う頻度が多すぎること、その友達が好きなこと）は本文になく、書き手しか知らない。末尾に「笑」を付けても neg のままだったので、気持ちを読むための情報が入力に足りていなかったと考えられる。人が読んでも neg と付ける可能性があり、ラベルの基準（書き手の本当の気持ち）そのものの限界でもある。
なお、LLM には各投稿を1回ずつしか聞いていないので、答えの揺れは確かめていない。

**どちらの誤りが痛いか**
用途によって変わる。運営への苦情を拾いたいなら、皮肉のネガを pos と見落とすルールの誤り（10）が痛い。推しや友達への好意を集めたいなら、照れ隠しを neg とする誤り（4・5）が痛い。

## 生成AIの利用申告

- **Claude Code（Claude Opus 5.5）**：課題条件の整理、リポジトリの雛形と `src/run.py` の作成・動作確認、単語リストとタスク定義・考察・この README の文の下書きに使った。内容は自分で確認し、ラベルと判断理由は自分で決めた。
- **Claude（チャット）**：ギャル語・オタク語の例文を出させ、データの型を考える参考にした。データの文は自分で書いた。
- **Claude Sonnet 5.5**：手法の一つとして、投稿のポジ／ネガ判定に使った（「設定」を参照）。
